# Marca — assets oficiales

Los assets definitivos los proporciona el administrador de la liga. Las
carpetas de abajo son **placeholders**: no contienen ningún logo ni trofeo
generado, a propósito, para que nada provisional acabe publicado como si fuera
oficial.

```
assets/branding/
├── league-logo/   Logo oficial de Liga Estabanquitos 2026-1
└── trophy/        Trofeo oficial
```

Formatos y tamaños esperados: ver
[docs/branding-and-assets.md](../../docs/branding-and-assets.md).

Uso de material de Clash Royale y texto de descargo obligatorio: mismo
documento.
